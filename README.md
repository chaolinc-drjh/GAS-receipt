# 🧾 雲端領據管理系統 (Cloud Receipt Management System)

這是一套基於 **Google Apps Script (GAS)** 與 **Google Sheets** 所開發的輕量、高效且極具彈性的「雲端領據管理系統」。專為學校或機關團體設計，旨在解決紙本領據開立繁瑣、出納入帳通知不易、以及後續查詢困難等痛點。

---

## ✨ 系統亮點 (Highlights)

### 1. 🚀 無痛轉移與高擴充性 (Dynamic Configuration)
系統的所有客製化參數（包含網域白名單、預設請款單位、匯入專戶清單、系統寄件者信箱、列印範本檔等）皆已抽離至 Google 試算表的 `CONFIG` 工作表中。**其他單位只需複製試算表並修改 `CONFIG`，即可完全無痛轉移與上線使用**，程式碼零修改！

### 2. 🔐 嚴謹的角色權限控制 (Role-Based Access Control)
系統內建四種層級的權限管理，確保資料安全：
*   **一般使用者 (User)**：可填寫領據、列印 PDF、並在建檔 7 日內編輯自己建立的領據。具備「複製新增」功能，快速建立相似領據。
*   **出納/管理員 (Admin)**：擁有專屬的管理面板，可一鍵切換領據的「入帳狀態」。系統會在確認入帳時，**自動發送 Email 通知**給原請款人，大幅減少來回溝通成本。
*   **超級管理員 (Super Admin)**：具備最高權限，可執行「歷史資料封存 (Archive)」，將舊資料搬移至歷史工作表，保持系統輕量與運作效能。
*   **未授權人員 (Guest)**：非指定網域之使用者無法進入系統；屬該網域但未經授權者，僅能以「唯讀模式」查詢列表，系統會自動鎖定所有編輯、列印與作廢功能 (顯示 🔒 圖示)。

### 3. 📄 自動化 PDF 領據生成 (PDF Generation)
使用者填寫完畢後，只需點擊「列印 PDF」，系統便會自動將資料帶入預先設計好的 Google Docs 範本中，瞬間產出格式統一、美觀的 PDF 領據，供列印或電子留存。

### 4. 🎨 現代化與響應式介面 (Modern & Responsive UI)
前端採用 **Bootstrap 5** 開發，提供流暢的頁籤切換、動態過濾器 (Filter) 以及直覺的進度條視覺化 (Visual Progress Bar)。無論是使用桌機、平板或手機，皆能獲得極佳的操作體驗。

### 5. 💰 金額自動防呆與轉換 (Smart Amount Conversion)
支援將阿拉伯數字金額自動轉換為「新台幣中文大寫金額」（例如：1000 轉換為 壹仟元整），避免人為填寫錯誤與竄改風險。

## 🛠️ 安裝與部署指南 (Deployment Guide)

### 第一步：準備 Google 試算表 (Database & Config)
1. 建立一個全新的 Google 試算表。
2. 建立以下四個工作表 (Sheet)：
    *   **領據紀錄**：存放所有的領據資料。 (需包含：`領據號碼`, `建檔日期`, `請款單位`, `計畫名稱`, `金額`, `金額大寫`, `狀態`, `連絡電話`, `網路電話`, `備註`, `匯入帳號`, `帳號`, `製表人`, `製表人Email`, `製表人確認`)
    *   **封存**：存放已封存的領據資料。(與領據紀錄同欄位名稱)
    *   **USER**：使用者清單 (需包含：`帳號`, `姓名`, `電話`, `VOIP`, `角色(E欄)`)。角色請填入 `ADMIN` 或 `SUPER_ADMIN`，若為一般使用者則留空 (僅能觀看)。
    *   **CONFIG**：系統核心設定表。

### 第二步：設定 CONFIG 工作表
請在 `CONFIG` 工作表依照以下位置填寫貴單位的專屬資料：
*   **A2:A5**：允許登入的 Google Workspace 網域 (例如 `@xxjh.ylc.edu.tw`)。
*   **B2**：Google Docs 列印範本的檔案 ID (Template ID)。
*   **C2**：自動發送信件的寄件者 Alias (例如 `noreply@yourdomain.edu.tw`)。
*   **D2**：系統網頁的 Favicon 圖片 ID (Google Drive Image ID)。
*   **E2**：預設的「請款單位」名稱 (例如 `雲林縣政府`)。
*   **F2:F8**：支援的匯入專戶名稱 (例如 `保管金專戶`, `午餐專戶`)。
*   **G2:G8**：與 F 欄對應的實體銀行帳號。

### 第三步：部署程式碼 (Google Apps Script)
1. 點擊試算表選單的 **擴充功能 > Apps Script**。
2. 透過 Clasp 工具或手動將 `code.js`, `Index.html`, `JavaScript.html`, `Stylesheet.html` 複製到專案中。
3. **首次授權與測試**：
    *   **首次授權**：在編輯器上方工具列選擇 `setupPermissions` (最下方) 函式並點擊「執行」 (右上角的播放按鈕)，完成首次部署必備的權限授權。
    *   **測試發信**：選擇 `testNoreplyEmail` (倒數第二個) 函式並點擊「執行」 (右上角的播放按鈕)，可先行測試系統是否能成功寄發 Email。
4. 點擊右上角選單 **部署 > 新增部署作業**，選擇 **網頁應用程式**。
5. 執行身分選擇 **「我」**，存取權限選擇 **「網域內的所有人」或「所有人」**，完成發布！

## 📖 操作說明 (Operation Instructions)

### 📝 新增與編輯 (一般使用者)
1. 登入系統後，點擊 **「填寫與編輯領據」** 頁籤。
2. 依序填寫受款人、金額、請款單位與匯入帳號 (由 CONFIG 自動載入選項)。
3. 提交後，系統將自動跳轉至列表，並標示 `新入帳!` 圖章。
4. 若需修改，在建檔 7 天內，點擊列表右側的 🟩 **編輯按鈕** 即可。

### 🔍 查詢與列印 (所有網域內註冊人員)
1. 點擊 **「查詢與列印」** 頁籤。
2. 可點擊 **「使用者姓名」** (左上角)快速過濾我的領據資料。
3. 可點選 **「經費入帳進度」**：
    * 左側實心進度條，查詢已入帳或部分入帳
    * 右側空心進度條，查詢未入帳
4. 點擊列表右側的 🖨️ **列印按鈕**，系統會開啟新分頁並產生 PDF。
5. 若有相似資料，點擊 📄 **複製新增按鈕** 可將該筆資料帶入表單作為草稿。

### 🛡️ 審核與入帳 (出納管理員)
1. 管理員 (Admin) 登入後，將會看到專屬的 **「管理員操作」** 頁籤。
2. 可利用關鍵字與金額(比輸入搜尋金額大的餘款，按金額大小遞增排序)進行快速搜尋。
3. 可點選 **「經費入帳進度」**：
    * 左側實心進度條，查詢已入帳或部分入帳
    * 右側空心進度條，查詢未入帳
4. 確認款項已匯出後，點選右側的 **「登記入帳」**。
5. **系統會在背景自動寄發 Email 通知該筆領據的建立者，提示款項已入帳！**
6. 登記入帳後，製表人於下次登入系統時，會有提示視窗告知經費已入帳。

### 📦 歷史資料封存 (超級管理員)
1. 超級管理員 (Super Admin) 登入後，管理員頁籤最下方會出現 **「資料封存與維護」** 區塊。
2. 設定指定年份 (例如 2023)，點擊封存。
3. 系統會自動將該年份以前的領據從「領據紀錄」搬移至歷史工作表 (例如 `Archive_2023`)，維持主系統的查詢速度。
